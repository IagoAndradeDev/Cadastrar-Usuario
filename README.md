# Cadastro de Usuários

Projeto desenvolvido como atividade prática para aprender e aplicar conceitos de desenvolvimento Full Stack, trabalhando na integração entre frontend, backend e banco de dados.

A aplicação permite realizar o cadastro de usuários, explorando a comunicação entre diferentes tecnologias e a organização de um projeto completo.

## 🚀 Tecnologias utilizadas

- **Node.js** — ambiente de execução JavaScript no backend.
- **Vite** — ferramenta de desenvolvimento e inicialização do frontend.
- **Tailwind CSS** — estilização e construção da interface.
- **Axios** — realização de requisições HTTP entre frontend e backend.
- **Prisma ORM** — gerenciamento e comunicação com o banco de dados.
- **MongoDB** — banco de dados NoSQL para armazenamento dos usuários.
- **API REST** — criação e integração de endpoints para operações com usuários.
- **CORS** — configuração da comunicação entre frontend e backend.

## 📚 O que aprendi

Durante o desenvolvimento, pratiquei conceitos importantes para a construção de aplicações Full Stack:

- Criação e configuração de um servidor com Node.js.
- Desenvolvimento e funcionamento de uma API REST.
- Comunicação entre frontend e backend utilizando Axios.
- Integração com MongoDB através do Prisma ORM.
- Estilização de interfaces utilizando Tailwind CSS.
- Configuração de projetos com Vite.
- Funcionamento e configuração do CORS.
- Organização de pastas e separação de responsabilidades.
- Integração entre diferentes tecnologias em uma aplicação.

## 🎯 Objetivo

Consolidar os conhecimentos adquiridos em desenvolvimento web, entendendo na prática como as tecnologias do frontend, backend e banco de dados trabalham juntas para construir uma aplicação funcional.
